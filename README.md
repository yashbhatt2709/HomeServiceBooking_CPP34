# Home Service Booking System

**Project Code:** CPP34  
**Enrollment Number:** IU2541230474

## Project Overview

Home Service Booking is a menu-driven C++ console application designed to manage home service bookings. It organizes customer details, worker information, available services, and booking records.

## Features

- Add and display customer and worker records
- View available home services and prices
- Book a service
- Search, update, and delete bookings
- Generate a booking report
- Save and load booking information using file handling

## Object-Oriented Programming

The project demonstrates:

- Classes and objects
- Encapsulation
- Constructors and destructors
- Inheritance
- Runtime polymorphism
- Dynamic memory allocation
- File handling
- Modular programming using header and implementation files

## Project Structure

- `Source/` — C++ source and header files
- `Data/` — booking data
- `Diagrams/` — UML diagrams and their source files
- `Home_Service_Booking_Project_Report.docx` — project report

## Requirements

- A C++ compiler supporting C++11 or later
- A terminal or command prompt

## Build and Run

Open a terminal in the project root directory and follow the build instructions in `README.txt`.

Run the application from the project root so that relative data-file paths work correctly.
